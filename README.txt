NIVEX LAG TESTER — Android Studio project

This project is a visual simulation/demo only. It does not connect to, modify, or interact with Free Fire or Free Fire MAX. Freeze/Ghost/Telekill buttons only display local demo status messages. It does not include cheats, anti-ban functionality, or gameplay modification.

BUILD APK:
1. Install Android Studio on a computer.
2. Open this folder as an existing project.
3. Allow Gradle sync and install the required Android SDK (compile SDK 35).
4. Choose Build > Build APK(s).
5. The debug APK is usually created under app/build/outputs/apk/debug/app-debug.apk.

No APK was compiled in this environment; this ZIP contains the source project.
